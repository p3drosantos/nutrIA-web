# 🥗 NutrIA Web

Frontend da plataforma NutrIA, uma aplicação SaaS fitness com geração inteligente de dietas utilizando IA generativa.

A aplicação permite que usuários criem contas, gerem dietas personalizadas com IA, acompanhem refeições e visualizem seu histórico nutricional através de uma dashboard moderna e responsiva.
